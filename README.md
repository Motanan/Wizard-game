# 🧙‍♂️ الساحر مرلين — لعبة تخمين سحرية للأطفال

لعبة ويب بسيطة وجذابة باللغة العربية: فكّر في **رقم** أو **فاكهة** أو **شخصية
مشهورة**، والساحر مرلين حايسألك كام سؤال ويحاول يخمّن إجابتك بالسحر!

## طريقة اللعب

1. اضغط "يلا نبدأ!" واختار فئة (رقم / فاكهة / شخصية مشهورة).
2. فكّر في حاجة من الفئة دي في راسك.
3. جاوب على أسئلة الساحر (أيوة / لأ / مش متأكد، أو أكبر / أصغر بالنسبة للأرقام).
4. الساحر حايخمّن! لو صح، احتفل معاه 🎉. لو غلط، حايحاول تاني لغاية ما يعرف أو يستسلم بابتسامة.

## طريقة التشغيل محليًا

ما فيه أي عملية بناء (build) مطلوبة — الملفات HTML/CSS/JS عادية بالكامل.
شغّل أي سيرفر ستاتيك بسيط من مجلد المشروع، مثلاً:

```bash
python3 -m http.server 8080
# افتح المتصفح على http://localhost:8080
```

أو افتح ملف `index.html` مباشرة في المتصفح.

## بنية المشروع

```
index.html         هيكل الصفحة، ونموذج الساحر ثلاثي الأبعاد (GLB)
assets/models/      ملفات النموذج ثلاثي الأبعاد لمرلين (أربع وضعيات)
tools/generate_merlin_poses.py  السكربت اللي بيولّد وضعيات النموذج
css/style.css      كل التصميم والحركات
js/data.js          بيانات الفواكه والشخصيات وأسئلتها
js/engine.js        محرك التخمين (بحث ثنائي للأرقام، واختيار أذكى سؤال للفواكه/الشخصيات)
js/app.js           التحكم في الشاشات وربط كل حاجة ببعض
```

## كيف الساحر بيخمّن؟

- **الأرقام:** بحث ثنائي كلاسيكي (Binary Search) بيضمن الوصول للرقم الصح
  خلال حوالي 7 أسئلة بس.
- **الفواكه والشخصيات:** كل عنصر ليه مجموعة صفات (لونه، شكله، إلخ). في كل
  دور، الساحر بيختار السؤال اللي حايفرّق أكتر بين المرشّحين المتصدّرين
  (زي فكرة الـ information gain)، وبيحدّث درجة كل مرشّح بعد كل إجابة، لغاية
  ما يوصل لتخمين واثق منه.

## نموذج الساحر ثلاثي الأبعاد

الساحر معروض كنموذج glTF/GLB ثلاثي الأبعاد (عبر مكتبة `<model-viewer>`) بدل
رسمة SVG، وليه أربع وضعيات (`merlin-idle.glb` / `merlin-thinking.glb` /
`merlin-happy.glb` / `merlin-sad.glb`) بتتبدّل حسب حالة اللعبة. السكربت اللي
بيولّد الوضعيات موجود في `tools/generate_merlin_poses.py` — شغّله بـ
`python3 tools/generate_merlin_poses.py` لو داير تعدّل الوضعيات أو تضيف واحدة
جديدة (محتاج `numpy` و `Pillow`).
